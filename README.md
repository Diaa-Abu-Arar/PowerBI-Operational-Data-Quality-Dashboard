# Power BI Operational Reporting, Data Quality & KPI Dashboard

## Project Overview

This Power BI project presents an operational reporting, data quality, and KPI monitoring dashboard designed for a humanitarian service-delivery environment. The dashboard was built to improve visibility over program performance, beneficiary reach, reporting quality, and management follow-up across multiple governorates, offices, and program streams.

The project reflects a practical Business Intelligence workflow using structured Excel data, Power Query for data preparation, and Power BI for interactive dashboard development. It focuses not only on visualization, but also on reporting discipline, validation controls, and governance-oriented monitoring.

---

## Business Context

In humanitarian and nonprofit operations, program teams often manage large volumes of activity-level data across different offices, locations, and service streams. Without a structured reporting system, it becomes difficult to monitor performance, detect data issues, follow up on delayed submissions, and identify records that require review.

This dashboard was designed to support managers and coordination teams by transforming operational records into clear, interactive views that help answer questions such as:

- How many beneficiaries were reached?
- Which governorates, offices, or program streams have the highest activity?
- What is the achievement rate over time?
- Where are late submissions or records needing review concentrated?
- What types of data quality issues are occurring?
- Which records require follow-up or validation?

## Data Preparation and Validation Logic

The dashboard was developed using structured operational data in Excel. The preparation process included:

- Standardizing field names and reporting categories
- Cleaning and formatting date fields
- Preparing controlled fields for governorate, office, program stream, and validation status
- Creating calculated columns and measures for KPI monitoring
- Building validation checks for missing values, mismatches, duplicate IDs, and late submissions
- Creating flags for records that require review
- Structuring the dataset to support filtering and drill-down analysis

The project demonstrates how data quality rules can be integrated directly into a reporting dashboard to support both analysis and operational governance.
